# E-shop clothing: Next-category prediction

Group 01 statistics project using the 2008 e-shop click dataset. Predict the next
product category within a session and compare current-click features with
current and earlier-click features. This is not purchase prediction.

- Start with [Setup and collaboration](SETUP_AND_COLLABORATION.md).
- Open [the notebook](Group01_EShopClothing.ipynb) from this directory.
- Read [project requirements](PROJECT_CONTEXT.md), [responsibilities](TEAM_RESPONSIBILITIES.md),
  and [task status](TASK.md).

Sections 1–11 are implemented. Sections 12–18 contain implementation guidance
and comment-only code placeholders; sections 19–21 contain writing guidance.
No model or reference-rule results have been generated yet.

Use Python 3.11 and `requirements.txt`. The repository includes source data and
the verified train/test exports; setup commands are in the collaboration guide.

Validation without modifying data or notebook outputs:

```bash
python tools/validate_preparation.py
```

The data description includes the requested source citation. Preserve that file
and cite the source when presenting this work. The repository is private;
collaborators need an invitation from the owner.
